# Open-data coverage assessment — Spanish from English

Checked: 2026-11-05

## Verdict

**Enough to build a useful, complete progression map and a CEFR-aligned Hungarian explanation curriculum. Not enough to claim exact Duolingo grammar coverage for every individual unit without occasional in-app confirmation.**

This is a positive result: the learner can receive coherent explanations that follow the actual broad Duolingo path. The system must distinguish course themes from confirmed grammar objectives.

## Source A — Duolingo Data (community-maintained)

Main index: https://duolingodata.com/

Spanish from English course: https://duolingodata.com/dat/esfen991.html

Different lesson objectives: https://duolingodata.com/dat/esfen991-d.html

Version history: https://duolingodata.com/dat/esfen-versions.txt

The main index page was observed on 2026-11-05 and reports an index update date of 2026-10-20. Spanish from English is listed as CEFR B2, 991 units, 8,415 lessons, 1,166 stories, with a 2026-09 version.

The version history identifies a 2026-09-02 snapshot with 991 units, 3,555 different lessons, 1,166 stories, 1,340 radios and 58 adventures.

The detailed 991-unit path page is dated 2026-03-02 and reports 8,346 lessons and 1,128 stories. These counts conflict with the newer main index, so the page-level counts must be treated as an older snapshot. The 991-unit section structure remains a useful high-level orientation, but current app rollout can differ.

### What source A gives us

- Course direction: Spanish from English.
- Eight sections and CEFR labels: Intro, A1, A1, A2, B1, B1, B2, B2.
- Unit counts per section: 10, 31, 30, 60, 250, 250, 180, 180.
- Unit-level communication themes across the path.
- A separate list of teaching-objective/debug-name labels for different lesson types.
- Useful clues about topic progression and functional communication.

### What source A does not give us reliably

- A complete grammar objective per unit.
- A verified ordering of individual grammar rules.
- All new vocabulary introduced in each lesson.
- Every example sentence, accepted answer or exercise.
- The exact path variant assigned to an individual user's account at a particular moment.

The detailed different-lessons page mostly labels lesson types and teaching objectives. A label such as "Discuss your diet" indicates a communication theme, not a grammar rule.

## Source B — Instituto Cervantes Plan Curricular (PCIC)

Official institutional description:
https://cervantes.org/es/sobre-nosotros/publicaciones/plan-curricular-instituto-cervantes-niveles-referencia-espanol

Online index:
https://cvc.cervantes.es/ensenanza/biblioteca_ELE/plan_curricular/indice.htm

The PCIC aligns its reference contents with the six CEFR levels. It includes inventories for grammar, pronunciation/prosody, orthography, pragmatic strategies, discourse genres, and lexical notions. Its grammar inventory covers nouns, gender and number, pronouns, interrogatives, adverbs, indicative tenses, subjunctive tenses, imperative, non-finite verb forms, and phrase-level agreement.

### What source B adds

- A structured grammar taxonomy across A1–C2.
- Level-sensitive reference for deciding when a concept is normally introduced or expanded.
- A way to identify prerequisites and avoid teaching advanced topics too early.
- A systematic checklist to ensure explanations cover more than isolated Duolingo sentence patterns.

### Limitation

PCIC is a reference curriculum, not Duolingo's own syllabus. It must not be used to claim that a grammar point is taught in a particular Duolingo unit.

## Source C — Instituto Cervantes AVE Global curriculum

Curriculum overview:
https://shanghai.cervantes.es/es/cursos_espanol/cursos_en_linea_espanol/cursos_ave.htm

The overview provides course and theme structure from A1 through C1. Theme PDFs show session-by-session communication functions, grammar and vocabulary.

### Example: nutrition / food

Duolingo Spanish-from-English Section 2 Unit 22 is titled "Discuss your diet" in the public path index.

Instituto Cervantes AVE Global A1.1 Topic 3 is "La alimentación" (food/nutrition). Its public topic PDF lists, among other items:
- indefinite pronouns algo/nada;
- interrogative cuánto;
- present-tense querer and preferir (e>ie);
- definite vs. indefinite articles;
- poner and irregular -go verbs;
- demonstratives este/ese/aquel;
- agreement of cuánto/-os/-as;
- noun–adjective agreement;
- estar + adjective for evaluation;
- exclamative qué;
- recomendar and poder;
- gustar (first and second person);
- impersonal se + third-person verb.

This demonstrates that an independent, official A1 thematic syllabus can enrich a Duolingo unit's communicative theme with realistic grammar and vocabulary candidates.

**It does not prove that all or any of these grammar points are in Duolingo's Unit 2.22.** They are a candidate reference pool. The exact Duolingo match requires evidence from that unit's own Guidebook or exercises.

## Coverage matrix

| Need | Open data coverage | Confidence |
|---|---|---|
| Overall course and section structure | Duolingo Data | High, with version caveat |
| Unit-level communication themes | Duolingo Data | High for public snapshot |
| Lesson-type / teaching-objective labels | Duolingo Data | Medium–high |
| Grammar taxonomy by CEFR | PCIC | High as an independent reference |
| Grammar and vocabulary by theme/session | AVE Global PDFs | High for AVE syllabus, not for Duolingo |
| Exact grammar introduced in a particular Duolingo unit | Not supplied by these public sources | Low until verified |
| Exact unit content currently shown to this learner | Must be checked in app | User-specific |

## Recommended teaching model

Build the explanation curriculum from three linked layers:

1. **Duolingo path layer** — section, unit, topic, and communication objective. This tells us what the learner is trying to talk about.
2. **CEFR/PCIC layer** — grammar and pragmatic prerequisites appropriate to the section's level. This supplies a structured teaching reference.
3. **AVE thematic layer** — optional topic-to-grammar and topic-to-vocabulary crosswalk. This provides practical candidates for food, travel, work, family, feelings, health, and other themes.

For each unit, the tutor should:
- identify the unit's communication theme;
- generate a short list of likely relevant grammar candidates from PCIC/AVE;
- distinguish previously introduced structures from possible new ones;
- teach confirmed foundational grammar where needed;
- label uncertain grammar as a supporting explanation, never as an official Duolingo objective;
- ask for an in-app Guidebook screenshot only when the exact new grammar matters or an inference would materially affect the lesson.

## Final assessment

The open data is sufficient to avoid teaching a disconnected, generic Spanish course. It is sufficient to build a detailed and useful Hungarian-language companion that tracks the Duolingo course's themes, sections and CEFR progression.

It is not sufficient to reconstruct Duolingo's exact per-unit grammar sequence. The companion can nevertheless work well by following the course themes and using PCIC/AVE as an independent pedagogical reference, while marking uncertainty honestly.
